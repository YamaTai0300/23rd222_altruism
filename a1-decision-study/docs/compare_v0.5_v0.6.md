# v0.5 → v0.6 の比較（2026-11-09）

v0.6 は研究室のオンライン実験マニュアル『Qualtrics とクラウドワークスの使い方』と計画書 v0.6（募集を CrowdWorks に）に合わせた版。
画面構成（9 ページ）、順序のランダム化、質問紙、DG、解析スクリプトは v0.5 と同じ。変わったのは参加資格の文言、終了画面の ID、照合・支払いのツール。
ソースの差分は `diff_v0.5_to_v0.6.patch`（docs/ を除く）。Qualtrics 版の対応する変更は `../../qualtrics/README.md`（r3）。

## 文言（参加者に見える）

| 画面 | v0.5 | v0.6 | 理由 |
| --- | --- | --- | --- |
| 同意（`eligible_check`） | 私は 18 歳以上で、[大学名] に在籍する学生です。 | 私は 18 歳以上で、日本語を母語としています。 | 募集が CrowdWorks（日本語母語の 18 歳以上）になり、学生の限定をやめた。マニュアルの「母語が日本語であること」のチェック |

| 終了（本文） | あなたの参加者コードは下の通りです。メモや画面の保存などで控えてください。 | あなたの実験 ID は下の通りです。CrowdWorks の作業ページに戻り、フォームにこの実験 ID を入力して「作業を完了する」を押してください。／実験 ID はメモや画面の保存などで控えてください。入力がないと報酬をお支払いできません。 | マニュアルの手順（調査完了 ID を CW のフォームに入力して作業完了） |
| 終了（ラベル） | 参加者コード | 実験 ID | 同上 |

## 変数

| 変数 | v0.5 | v0.6 |
| --- | --- | --- |
| `exp_id` | なし（終了画面は oTree の `participant.code`） | 追加。10 桁の数字、`creating_session` で `secrets` により発行、セッション内で一意。終了画面に表示し、CSV に出る |
| `eligible_confirm` | 18 歳以上かつ対象大学の学生 | 18 歳以上かつ日本語が母語（変数名・型は同じ） |
| `app_version` | v0.5-pilot | v0.6-pilot |

`participant.code` はこれまでどおり残る（管理画面・エクスポート）。Qualtrics 版（r3）では `exp_id` を埋め込みデータの乱数で発行し、変換で `participant.code` にも入れる。

## ツール

| ツール | v0.5 | v0.6 |
| --- | --- | --- |
| `tools/match_cw_ids.py` | なし（照合は想定していない） | 新規。CW の承認待ち一覧と調査データを実験 ID で照合し、approve / check / reject、未申告の一覧、pairing 用の連絡先 CSV を出す |
| `tools/pairing.py` | code = `participant.code`、連絡先 = メールアドレス（実験の外で集める） | code = `player.exp_id`、連絡先 = CW のユーザー名（match_cw_ids.py の出力）。`--realize-pairs N`（案 B）、`cw_extra_yen` 列 |
| `tests.py` | — | `exp_id` が 10 桁・一意であることを検査（v0.6 ではまだ実行していない） |
| `99_synthetic.R` | — | `player.exp_id` 列を追加（R は v0.6 ではまだ実行していない） |

## 手続き（計画書 v0.6 との対応）

- 募集: CW のタスク（単価 300 円、定員 150、作業時間の上限 60 分、入力フォーム「実験 ID」= 20 文字以下・重複を認めない、承認率 95% 以上）。設定は CW 側で行う
- 締切後: 4 時間待つ → 募集終了・公開終了 → `match_cw_ids.py` → CW で承認・非承認（14 日以内） → `pairing.py` → DG 分を個別発注 → 事務書類 3 点で検収
- 連絡先（メールアドレス）は集めない。CW のユーザー名は回答データと別に保管し、検収後に削除する
